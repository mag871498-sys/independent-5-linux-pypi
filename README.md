# Самостійна робота №5

Пакет `study5-hello-lab` надає функцію `hello()` та демонструє збирання wheel/sdist і публікацію в локальний devpi.
Після запуску сховища встановіть його командою `pip install --no-cache-dir --no-deps --index-url http://127.0.0.1:3141/student/lab/+simple/ study5-hello-lab==0.1.0`.
Послідовність Linux-вправ, запуск сховища й тест Molotov наведені в [LAB.md](LAB.md), а звіт зі скриншотами розташований у `reports/output/pdf/`.
